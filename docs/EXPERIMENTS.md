# 实验记录与评估口径

本文档记录项目中的关键迭代、已验证结论与尚未验证的假设。目标是让实验事实与推断保持分离，避免用训练 loss 或少量真机观察替代完整评估。

## 实验时间线

### ACT：示教质量迭代

**第一轮**

- 数据：20 条示教。
- 采集特点：目标位置变化较大；遥操作轨迹中有较多停顿、犹豫和不连续动作。
- 结果：真机抓取效果较差。
- 判断：数据同时存在任务分布较宽和动作质量不稳定的问题，仅凭本轮实验不能将失败归因于模型能力。

**第二轮**

- 数据：重新采集 30 条连续、一致的高质量示教。
- 结果：成功完成固定位置方块抓取。
- 已验证结论：示教连续性、一致性和采集规范是影响模仿学习效果的重要因素。

### π0.5：云端推理与本地执行

- 数据：51 条示教。
- 部署：云端 GPU 推理，本地机械臂采集观测并执行动作。
- 结果：固定场景下可以完成任务。
- 系统现象：存在通信延迟、观测帧过期和断联，动作连续性受到影响。
- 评估口径：没有经过严格设计的重复测试，因此只报告定性结果，不给出成功率。
- 已验证结论：跨网络推理链路会引入影响闭环控制的工程问题。

### SmolVLA：从固定分布到随机位置

**初始数据**

- 红色目标任务：50 条示教。
- 蓝色目标任务：50 条示教。
- 现象：红蓝物体同场时，目标选择与抓取不稳定。
- 假设：颜色与固定位置之间的相关性可能导致捷径学习；该机制尚未通过消融实验单独验证。

**蓝色任务数据重构**

- 在原 50 条蓝色任务示教上新增 50 条随机位置示教。
- 合并后的蓝色任务数据：100 个 episode，共 52,605 帧。
- 保持任务指令：`Put the blue cube into the right box`。
- 结果：重训后，在当前测试范围内完成 13/13 次成功抓取。
- 已验证结论：扩大本任务的位置覆盖后，当前分布内的真机表现明显改善。

**训练空间覆盖之外**

- 测试次数：约 10 次。
- 目标选择：能稳定选择正确颜色目标。
- 最终抓取：约 4–5 次成功。
- 解释：在这组观察中，语义层面的目标选择比动作层面的精确抓取更稳定，即 Semantic Generalization 好于 Action Generalization。
- 限制：测试数量较少，“约 4–5/10”用于描述现象，不作为统计显著的成功率估计。

## 结果口径

| 表述 | 证据级别 | 使用方式 |
|---|---|---|
| 当前测试范围 13/13 成功 | 已记录的真机测试结果 | 可量化展示，但必须附带测试范围限定 |
| 范围外约 10 次中抓取成功 4–5 次 | 观察性结果 | 用于说明泛化落差，不写成精确成功率 |
| π0.5 固定场景可完成任务 | 定性真机结果 | 不给出未经严格测试的成功率 |
| 约 2–3 Hz 本地推理 | 端到端观测值 | 不直接归因于 GPU，需进一步拆分测量 |
| 颜色—位置捷径学习 | 基于数据分布与行为的假设 | 使用“可能”，不能写成已证实根因 |
| 机械臂回差/刚性影响抓取 | 硬件层面的候选因素 | 使用“可能”，需专门实验量化 |

## 失败模式拆解

为避免只记录“成功/失败”，后续测试建议将一次 rollout 拆成以下阶段：

1. **目标选择**：是否选择指令要求的颜色。
2. **预抓取到达**：末端是否到达可执行抓取的位姿。
3. **夹爪闭合**：是否形成稳定夹持。
4. **搬运**：物体是否在移动中保持夹持。
5. **放置**：是否进入右侧目标盒并成功释放。

这一拆分可以区分语义错误、轨迹泛化错误与执行机构误差。

## 当前瓶颈假设

本地端到端推理频率约为 2–3 Hz，但根因尚未完全定位。候选因素包括：

- 模型前向与动作生成耗时；
- 双相机采集、编码、复制与 USB 带宽；
- 观测进入策略前的排队或帧过期；
- RTC/控制循环调度与动作执行等待；
- 其他主机资源竞争。

低成本 SO-101 硬件还可能受到关节回差、结构刚性和重复定位误差影响。上述因素目前均为候选解释，不能由现有结果单独确认。

## 建议的下一组实验

1. 对图像采集、预处理、模型前向、动作生成和下发分别打时间戳，定位 2–3 Hz 的主要耗时。
2. 建立位置网格，分别报告训练覆盖内、边界和覆盖外的阶段性成功率。
3. 固定视觉条件，重复执行相同关节目标，测量末端重复定位误差与回差。
4. 对比固定相机帧与实时相机帧、单相机与双相机输入，检查采集/USB 链路影响。
5. 增加光照、背景和干扰物变化，继续验证颜色语义是否稳定。
